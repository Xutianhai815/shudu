# 每日脑力报告设计

## 目标

在现有“大脑除锈完成”反馈基础上，增加一个轻量的“每日脑力报告”，让玩家完成关卡后能看到“今天我做了脑力训练”的即时记录。首版聚焦日内反馈，不做连续打卡压力、不做徽章系统、不做医学或疾病预防承诺。

## 范围

本次功能包含：

- 通关反馈中展示今日完成次数和今日除锈值。
- 菜单页“今日报告”从仅展示累计除锈，升级为展示今日训练摘要。
- 本地进度中增加轻量 `dailyReport` 数据，用于记录本地自然日内的完成情况。
- 保留现有 `completedLevelIds`、继续游戏、选关、通关弹层和累计除锈逻辑。
- 继续显示安全边界文案：`娱乐数值，不代表医学效果。`

本次功能不包含：

- 连续天数 streak、断签、补签或签到奖励。
- 称号、徽章、成就墙或分享卡。
- 云端统计、排行榜、社交关系或跨设备同步。
- 真实健康评分、认知能力测评、疾病风险、医学建议或健康收益承诺。
- 新关卡、新数独规则或广告变现。

## 产品定位

每日脑力报告是一个“游戏内训练回执”，不是健康报告。它表达的是：

- 玩家今天完成了主动思考。
- 游戏把这次思考记录成一个轻松、可见、可积累的娱乐反馈。
- 今日数据只用于增强完成后的正向感受，不制造压力。

推荐核心文案：

```text
今日脑力报告
今日除锈 +0.01%
已完成 1 次训练
```

推荐辅助文案：

```text
今日脑力状态：稳定发亮
```

安全边界：

```text
娱乐数值，不代表医学效果。
```

## 健康宣称边界

必须保持现有“大脑除锈”的娱乐化边界。每日数据只代表游戏内完成记录，不能暗示真实健康、认知或疾病风险变化。

禁止文案示例：

- “今日降低患病概率 0.01%”
- “连续训练可预防阿尔茨海默”
- “改善认知能力”
- “医学证明有效”
- “防止老年痴呆”

允许文案示例：

- “今日除锈 +0.01%”
- “已完成 1 次训练”
- “今日脑力状态：稳定发亮”
- “主动思考完成”
- “娱乐数值，不代表医学效果。”

## 用户体验

### 通关弹层

玩家完成当前关卡后，胜利弹层保持当前强反馈结构：

```text
大脑除锈完成
+0.01%
今日脑力光泽度
```

同时在统计区或副信息区增加今日报告信息：

```text
今日训练
1 次

今日除锈
+0.01%
```

如果玩家当天已完成多次训练，则展示更新后的今日值：

```text
今日训练 2 次
今日除锈 +0.02%
```

弹层仍保留：

- 错误数。
- 趣味副文案。
- 安全边界文案。
- `再来一局` 和 `下一关` 操作。

### 菜单页

菜单页现有“今日报告”卡片升级为真正的日内摘要。首版建议展示：

```text
今日报告
今日除锈 0.01%
娱乐指标 · 今日已完成 1 次训练
```

如果今天未完成训练但历史上有已完成关卡，可展示温和召回态：

```text
今日报告
今日除锈 0.00%
完成一局，给大脑做个热身
```

如果没有任何完成记录，也可以继续隐藏报告卡，避免首屏过早拥挤。

### 日期切换

每日报告按本地自然日计算。日期格式使用本地时区生成的 `YYYY-MM-DD`。

当玩家打开游戏或完成关卡时：

- 如果 `dailyReport.date` 等于今天，则继续累加今日数据。
- 如果 `dailyReport.date` 不是今天，则运行时视为今天的空报告；下一次保存进度时写回今天的日期。
- 历史累计关卡 `completedLevelIds` 不受每日重置影响。

## 数据模型

现有进度继续保留：

```js
{
  activeRun,
  completedLevelIds
}
```

新增可选字段：

```js
{
  dailyReport: {
    date: "2026-05-14",
    completionCount: 1,
    completedLevelIds: ["lab-02"]
  }
}
```

字段说明：

- `date`：本地自然日，格式 `YYYY-MM-DD`。
- `completionCount`：当天完成训练次数。首版可以按通关事件累计，允许同一关重复完成计数。
- `completedLevelIds`：当天完成过的关卡 id，用于后续扩展展示；首版不需要在 UI 中直接列出。

设计选择：

- `completedLevelIds` 继续表示历史已完成关卡集合，用于关卡卡片状态和累计除锈。
- `dailyReport.completionCount` 表示今天发生了几次完成事件，用于日内反馈。
- 同一关当天重复完成会增加今日训练次数，但不会让历史 `completedLevelIds` 重复。

异常数据处理：

- 缺失 `dailyReport` 时，视为今天 0 次。
- `date` 非字符串或日期不等于今天时，重置为今天 0 次。
- `completionCount` 非整数或小于 0 时，归零。
- `completedLevelIds` 非数组时，使用空数组。

## 架构

### `minigame/src/progress.js`

扩展进度模型的 normalize / serialize / restore 逻辑。

职责：

- 在 `EMPTY_PROGRESS` 中加入安全的 `dailyReport` 默认值。
- 读取旧存档时兼容没有 `dailyReport` 的情况。
- 过滤异常 `dailyReport` 数据，避免脏存档破坏菜单或通关反馈。

### `minigame/src/derust.js`

扩展除锈反馈生成能力。

建议新增或扩展函数：

```js
function getTodayKey(now = new Date()) {}
function createDailyReportSummary(dailyReport, todayKey, completedLevelIds) {}
function createNextDailyReport(dailyReport, levelId, todayKey) {}
```

职责：

- 生成本地自然日 key，格式为 `YYYY-MM-DD`，便于测试中注入日期。
- 生成菜单页今日报告摘要。
- 根据通关事件计算新的今日报告数据。
- 格式化 `今日除锈 0.01%`、`今日已完成 1 次训练` 等文案。
- 保持所有除锈文案和安全边界集中管理。

菜单摘要规则：

- 今日完成次数大于 0：显示今日除锈和今日训练次数。
- 今日完成次数等于 0 且历史 `completedLevelIds` 非空：显示温和召回态。
- 今日完成次数等于 0 且没有历史完成关卡：隐藏报告卡。

### `minigame/src/menu.js`

菜单布局继续只消费摘要数据，不直接计算日期或次数。

职责：

- 接收 `dailyReportSummary`。
- 把摘要放入现有报告卡片区域。
- 没有报告时保持现有隐藏行为。

### `minigame/src/renderer.js`

继续作为 Canvas 绘制层。

职责：

- 菜单报告卡片绘制今日文案。
- 通关弹层绘制今日训练相关统计。
- 不直接读取日期，不直接修改进度。

### `minigame/game.js`

继续作为运行时协调器。

职责：

- 在完成关卡时更新 `dailyReport`。
- 在菜单和通关弹层渲染前传入今日报告摘要。
- 保持现有 `applyStateChange -> persistProgress -> render` 链路。

## 错误处理

- 日期计算失败时，使用今天 0 次的安全默认值。
- 旧存档缺少 `dailyReport` 时，不显示错误，不清空历史完成关卡。
- 今日报告生成失败时，菜单可以隐藏报告卡；通关弹层仍显示基础“大脑除锈完成”反馈。
- 存储写入失败时沿用现有 `saveProgress` 行为，不阻塞游戏流程。

## 视觉方向

首版使用“轻量日报卡”方向：

- 菜单页卡片标题：`今日报告`。
- 主数值从 `累计除锈` 改为 `今日除锈`。
- 详情行突出今日完成次数。
- 配色延续深绿实验室底色和琥珀高亮。
- 不加入七日格子、火焰连续标识或徽章大图形。

通关弹层中的今日信息应轻量嵌入，不抢 `+0.01%` 的主视觉。

## 测试

新增或更新测试：

- `progress.test.cjs`：旧存档缺少 `dailyReport` 时返回安全默认值。
- `progress.test.cjs`：异常 `dailyReport` 字段会被归一化。
- `derust.test.cjs`：今日 0 次、1 次、多次训练的摘要文案正确。
- `derust.test.cjs`：同一关重复完成会增加今日训练次数，但历史完成集合不重复。
- `menu.test.cjs`：菜单布局接收并暴露今日报告摘要。
- `renderer.test.cjs`：菜单绘制 `今日除锈` 和 `今日已完成 x 次训练`。
- `renderer.test.cjs`：通关弹层绘制今日训练统计。
- `game-runtime.test.cjs`：debug 快速完成后写入 completed 存档，同时更新 `dailyReport`。
- 敏感词扫描继续确认不出现疾病、预防或医学承诺文案。

## 验收标准

- 完成第一局后，通关弹层显示今日训练信息。
- 返回菜单后，报告卡显示 `今日除锈 0.01%` 和 `今日已完成 1 次训练`。
- 同一天再次完成关卡后，今日训练次数和今日除锈值递增。
- 第二天打开或完成关卡时，今日报告从 0 开始，但历史已完成关卡状态保留。
- 旧存档仍可正常读取，继续游戏、选关、返回菜单、下一关、再来一局不退化。
- 不出现疾病名称、疾病风险、预防或医学承诺。
- 所有现有测试和新增测试通过。

## 后续扩展

后续可以基于该数据模型扩展：

- 连续除锈 streak。
- 每周脑力热力图。
- 趣味称号或徽章。
- 完成后分享卡。

这些扩展应单独设计，并继续遵守非医学、娱乐化的表达边界。
