# 大脑除锈反馈设计

## 目标

在玩家完成一轮数独关卡后，给出一个强记忆点、轻松、有传播感的正向反馈，让玩家直观感受到“我刚刚完成了一次有益的脑力训练”。反馈使用“大脑除锈”作为核心表达，用娱乐化数值增强爽感，但不做医学或疾病预防承诺。

## 范围

本次功能包含：

- 通关弹层中加入“大脑除锈完成”的反馈内容。
- 每次完成关卡增加一个娱乐化除锈数值，例如 `+0.01%`。
- 菜单页展示轻量累计反馈，例如“累计除锈 0.02%”。
- 完成关卡卡片可显示“已除锈”一类状态。
- 在反馈中加入明确安全边界文案，例如“娱乐数值，不代表医学效果。”

本次功能不包含：

- 医学建议、疾病风险评估、健康诊断或真实健康收益承诺。
- 使用“老年痴呆”“阿尔茨海默”“预防”“降低患病概率”等疾病相关表达。
- 分享卡、排行榜、连续打卡、云端统计或真实健康数据分析。
- 新的数独关卡、新玩法规则或广告变现。

## 产品定位

该功能不是医疗健康功能，而是数独小游戏里的“脑力奖励系统”。它要表达的是：

- 玩家完成了主动思考。
- 这次思考值得被看见和奖励。
- 数独实验室用一种好玩的方式给出“脑力小报告”。

推荐主文案：

```text
大脑除锈完成
+0.01%
今日脑力光泽度
```

推荐副文案：

```text
你的前额叶刚刚完成了一次俯卧撑。请继续保持嚣张。
```

推荐安全边界：

```text
娱乐数值，不代表医学效果。
```

## 健康宣称边界

必须避免把娱乐化数值包装成真实疾病风险变化。`+0.01%` 或类似数字只能解释为游戏内娱乐指标，不能解释为健康概率、疾病概率或医学收益。

禁止文案示例：

- “老年痴呆概率降低 0.01%”
- “降低阿尔茨海默风险”
- “预防认知衰退”
- “医学证明有效”
- “坚持玩可以防病”

允许文案示例：

- “大脑除锈完成”
- “今日脑力光泽度 +0.01%”
- “逻辑链路 +1”
- “娱乐数值，不代表医学效果”
- “你刚刚完成了一次主动思考”

设计依据：

- FDA 的 general wellness 边界通常更适合非疾病、低风险、一般健康表达。
- FTC 对健康相关广告要求有可靠科学证据支持。
- 阿尔茨海默相关机构对 brain training 降低痴呆风险持谨慎态度，不宜做疾病风险承诺。

参考：

- FDA General Wellness Policy for Low Risk Devices: https://www.fda.gov/regulatory-information/search-fda-guidance-documents/general-wellness-policy-low-risk-devices
- FTC Health Claims: https://www.ftc.gov/news-events/topics/truth-advertising/health-claims
- Alzheimer's Society Brain Training: https://www.alzheimers.org.uk/about-dementia/managing-the-risk-of-dementia/additional-treatments-for-dementia-risk/brain-training

## 用户体验

### 通关瞬间

玩家完成当前棋盘后，胜利弹层不只显示“完成”，还显示“大脑除锈完成”的脑力反馈。

弹层内容优先级：

1. 主标题：`大脑除锈完成`
2. 核心数值：`+0.01%`
3. 指标名：`今日脑力光泽度`
4. 辅助指标：`逻辑链路 +1`、`专注时间 3m` 等
5. 趣味副文案：`你的前额叶刚刚完成了一次俯卧撑。请继续保持嚣张。`
6. 安全边界：`娱乐数值，不代表医学效果。`
7. 操作按钮：`下一关`、`重开`，后续可加 `炫耀一下`

### 菜单页

如果已有完成关卡，菜单页可显示轻量累计反馈：

```text
今日报告
累计除锈 0.02%
娱乐指标 · 已完成 2 次训练
```

关卡卡片完成态从“已完成”升级为更有记忆点的“已除锈”。这能把通关后的爽点延续到菜单页。

### 再次进入

本功能不改变现有继续游戏和本地进度逻辑。玩家重新进入时，菜单照常展示继续按钮和关卡列表；累计除锈根据已完成关卡数量计算，不需要引入新的复杂存档结构。

## 数据模型

第一版不新增独立健康数据表。使用现有 `completedLevelIds` 推导娱乐指标：

```js
derustPercent = completedLevelIds.length * 0.01
```

展示时格式化为：

```text
0.01%
0.02%
```

若未来需要支持重复通关累计、每日统计或连续训练，可再扩展进度模型，例如：

```json
{
  "derust": {
    "totalCompletions": 3,
    "todayCompletions": 1,
    "lastCompletionDate": "2026-05-14"
  }
}
```

第一版暂不做该扩展，避免影响现有存档稳定性。

## 架构

### `minigame/src/derust.js`

建议新增纯函数模块，负责生成除锈反馈数据。

职责：

- 根据当前完成关卡和 `completedLevelIds` 计算通关反馈。
- 格式化 `+0.01%`、`累计除锈 0.02%` 等文案。
- 集中维护允许出现的趣味文案和安全边界文案。
- 保持可测试，不依赖微信 API 或 Canvas。

建议接口：

```js
function createCompletionFeedback(state, completedLevelIds) {}
function createDerustSummary(completedLevelIds) {}
```

### `minigame/src/renderer.js`

在现有胜利弹层和菜单渲染中消费反馈数据。

职责：

- 通关时绘制“大脑除锈完成”弹层内容。
- 菜单页绘制累计除锈摘要。
- 关卡卡片完成态显示“已除锈”。

### `minigame/game.js`

继续作为运行时协调器。

职责：

- 在 `renderGame` 前把当前 `completedLevelIds` 或反馈摘要传给渲染层。
- 不直接散落除锈文案和计算逻辑。
- 保持已有场景切换、保存和继续游戏流程。

## 视觉方向

通关弹层采用“强梗传播”风格：

- 深绿色实验室背景。
- 琥珀色高亮 `+0.01%`。
- 高对比主标题，适合截图传播。
- 保留实验室感标签，例如 `LAB RESULT`。
- 安全文案字号小，但必须可读。

菜单摘要采用更轻的方式：

- 不抢开始/继续按钮主视觉。
- 作为一张“今日报告”小卡片显示。
- 数值使用 `累计除锈 0.02%`，并标注 `娱乐指标`。

## 错误处理

- `completedLevelIds` 缺失、为空或数据异常时，除锈累计显示为 `0.00%` 或不显示摘要。
- 通关反馈生成失败时，不阻塞原有胜利弹层和下一关按钮。
- 不依赖真实时间、网络或远程配置。

## 测试

新增或更新测试：

- `derust.test.cjs`：完成 1 个关卡时生成 `+0.01%` 和安全边界文案。
- `derust.test.cjs`：完成多个关卡时累计数值正确。
- `derust.test.cjs`：异常 `completedLevelIds` 返回安全默认值。
- `renderer.test.cjs`：通关状态下绘制“大脑除锈完成”和 `娱乐数值，不代表医学效果` 不抛错。
- `renderer.test.cjs`：菜单有完成关卡时绘制累计除锈摘要。
- 回归现有进度、菜单、布局和 puzzle 测试。

## 验收标准

- 通关弹层显示“大脑除锈完成”和 `+0.01%`。
- 通关弹层显示“娱乐数值，不代表医学效果。”
- 菜单页在有完成关卡时显示累计除锈摘要。
- 已完成关卡卡片显示“已除锈”或同等表达。
- 不出现疾病名称、疾病风险、预防或医学承诺。
- 现有开始、选关、继续、返回菜单、下一关和重开流程不退化。
- 所有测试通过。

## 后续扩展

可在后续版本加入：

- 多条随机趣味副文案。
- 完成速度、错误数、连续天数影响不同娱乐称号。
- 截图分享卡。
- 每日除锈报告。
- “脑力实验室”成就墙。

这些扩展都应继续遵守非医学、娱乐化的表达边界。
