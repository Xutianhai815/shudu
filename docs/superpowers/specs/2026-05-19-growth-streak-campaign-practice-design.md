# 轻量成长系统、24 关闯关包与自由练习升级设计 Spec

## 背景

当前版本已经具备两条核心路径：

- `闯关挑战`：玩家从第一关开始推进，完成后进入下一关。
- `自由练习`：玩家可进入练习路径，按难度开始一局数独。

下一轮功能的重点不是增加更复杂的玩法，而是增强玩家“每天愿意回来玩一局”的动力。数独本身有烧脑门槛，所以成长系统必须轻、安静、低压力：让玩家看到自己持续练习和逐步推进，但不把游戏变成打卡任务、考试系统或商业化任务系统。

## 目标

- 增加 `连续练习记录`，让玩家感受到持续练习的正向价值。
- 将闯关包从 `12` 关扩展到 `24` 关，并让玩家清楚知道当前进度。
- 重新规划自由练习，使其从“手动选难度”升级为“带推荐的自适应训练路径”。
- 为后续完成反馈升级预留数据基础，但本轮不强制实现复杂统计页。
- 保持审核友好：不新增付费、广告、货币、排行榜、社交 PK、医疗化承诺或强签到奖励。

## 非目标

- 不做每日一题。
- 不做云存档、账号体系、好友榜、分享挑战或多人对战。
- 不做金币、道具、会员、商城、红包、兑换码或付费复活。
- 不做疾病预防、治疗效果、概率降低等医学承诺表达。
- 不把自由练习做成完整课程系统；本轮只做轻量推荐和难度递进。
- 不在首页展示 24 个关卡列表，避免首屏复杂。

## 功能一：连续练习记录

连续练习记录是下一轮最优先的成长能力。它回答的问题是：玩家不是只完成了一局，而是在持续训练。

### 计数规则

- 任意模式完成一局都计入当天练习，包括 `闯关挑战` 和 `自由练习`。
- 每个自然日只会让连续天数增加一次。
- 如果玩家今天完成至少一局，记录 `todayCompletedCount += 1`。
- 如果今天是上次完成日期的下一天，`currentStreak += 1`。
- 如果今天和上次完成日期相同，`currentStreak` 不变，只增加今日完成局数。
- 如果距离上次完成日期超过一天，`currentStreak` 重置为 `1`。
- `bestStreak` 记录历史最长连续练习天数。

### 数据字段

建议在本地进度中增加：

```js
{
  growthStats: {
    currentStreak: 0,
    bestStreak: 0,
    lastCompletedDate: null,
    todayDate: null,
    todayCompletedCount: 0,
    totalCompletedCount: 0,
    campaignCompletedCount: 0,
    practiceCompletedCount: 0
  }
}
```

### 是否统计已完成关卡

有必要统计，但要分开统计：

- `campaignCompletedCount`：只统计闯关完成数，用于 `已完成 x/24`。
- `practiceCompletedCount`：只统计自由练习完成局数，用于训练反馈。
- `totalCompletedCount`：统计所有完成局数，用于轻量成长反馈。
- `currentStreak`：只判断当天是否完成过至少一局，不区分模式。

这样既能支持连续练习，也能避免自由练习污染闯关进度。

### 展示方式

首页只展示非常轻的成长提示：

- `连续除锈 3 天`
- `今日已完成 1 局`
- `最长连续 7 天`

完成弹窗中可展示：

- `连续除锈 / 3 天`
- `今日训练 / 2 局`

### 文案边界

允许使用轻松表达：

- `连续除锈`
- `脑力热身`
- `今日训练`
- `保持节奏`

禁止使用：

- `预防老年痴呆`
- `降低患病概率`
- `医学证明`
- `治疗`
- `必须每天完成`
- `断签惩罚`

## 功能二：24 关闯关包

闯关模式需要从 `12` 关扩展到 `24` 关，让玩家有更明确的阶段目标。

### 关卡数量与编号

- 总关卡数：`24`。
- 关卡 ID：继续使用 `LAB-01` 到 `LAB-24`。
- 每关仍为经典 `9x9` 数独，不引入温度线、箭头或其他变体规则。
- 每关必须唯一解。
- 每关题面和终盘应尽量避免连续重复感。

### 难度曲线

建议难度分布：

| 关卡范围 | 难度 | 设计目标 |
| --- | --- | --- |
| `LAB-01` 到 `LAB-04` | `intro` | 建立信心，主要靠直接观察完成 |
| `LAB-05` 到 `LAB-10` | `easy` | 需要行列宫联动，但仍保持轻松 |
| `LAB-11` 到 `LAB-18` | `normal` | 鼓励使用草稿，进入标准数独节奏 |
| `LAB-19` 到 `LAB-24` | `hard` | 提供更长局专注体验，但控制在大众可完成范围 |

### 进度展示

有必要向玩家展示总关数，但要克制。

游戏页顶部建议显示：

- `第 5/24 关`
- `闯关挑战 · 简单`

首页闯关卡片建议显示：

- `闯关进度 5/24`
- 如果有未完成局：`继续第 5/24 关`
- 如果没有未完成局：`下一关 6/24`

完成弹窗建议显示：

- `已完成 5/24`
- 主按钮：`下一关`

不建议展示：

- 24 个关卡卡片列表。
- 锁定关卡墙。
- 星级评分。
- 失败次数统计。

### 最后一关完成

完成 `LAB-24` 后进入首轮完成状态：

- 完成弹窗标题可显示 `首轮闯关完成`。
- 主按钮显示 `进入自由练习`，引导玩家把已建立的能力迁移到自由训练。
- 不自动回到 `LAB-01`，避免玩家误以为进度丢失。

## 功能三：系统化自由练习

自由练习要从简单难度选择升级为低压力训练路径。它的目标不是通关，而是帮助玩家随时进入合适难度的一局。

### 入口规则

点击首页 `自由练习` 后：

- 如果存在未完成的自由练习局，直接恢复该局。
- 如果是首次进入自由练习且没有练习存档，进入难度选择页。
- 如果非首次进入但没有未完成局，根据历史练习和闯关进度提供推荐难度，同时允许用户自行选择。

### 推荐难度来源

推荐只作为建议，不强制。

优先级：

1. 如果玩家有自由练习历史，优先根据最近练习难度和完成情况推荐。
2. 如果玩家没有自由练习历史，但有闯关进度，根据当前闯关所在难度推荐。
3. 如果玩家没有任何历史，默认推荐 `热身`。

闯关进度到自由练习推荐映射：

| 闯关进度 | 推荐自由练习 |
| --- | --- |
| `LAB-01` 到 `LAB-04` | `热身` |
| `LAB-05` 到 `LAB-10` | `稳定` |
| `LAB-11` 到 `LAB-18` | `标准` |
| `LAB-19` 到 `LAB-24` | `进阶` |

### 自由练习难度命名

自由练习面向训练状态，不完全照搬闯关难度名。

- `热身`：对应 `intro` 题池。
- `稳定`：对应 `easy` 题池。
- `标准`：对应 `normal` 题池。
- `进阶`：对应 `hard` 题池。

页面上可显示：

- `推荐：稳定`
- `接近你当前闯关节奏`
- `也可以手动选择其他难度`

### 完成后下一局选择

自由练习完成一局后，不再只提供“再来一局同难度”。系统应选择下一局候选，并允许用户确认开始。

规则：

- 默认优先保持当前难度，避免跳跃太大。
- 如果玩家连续完成同一难度 `2` 局，下一局可以微微上浮一级。
- 如果当前已经是 `进阶`，继续在进阶题池中轮换。
- 如果玩家完成时间很长，不下调难度，只在文案上提示 `保持这个难度也很好`。
- 不根据过程中的填错判断升降级，因为过程不判断对错。

完成页按钮建议：

- 主按钮：`下一局`
- 次按钮：`换难度`

如果用户点击 `下一局`，进入系统推荐的下一题。如果点击 `换难度`，进入难度选择页。

### 自由练习题池

本轮可以先复用 `LAB-01` 到 `LAB-24` 作为题池，但自由练习不展示 LAB 编号为主身份。

选择策略：

- 根据目标难度从对应题池中选题。
- 优先避开最近完成或最近开始的题。
- 同一难度题池不足时允许重复，但不要连续重复同一题。
- 自由练习完成不写入闯关完成进度。

### 自由练习存档

建议保留独立存档：

```js
{
  practiceRun: {
    mode: 'practice',
    levelId,
    trainingDifficulty,
    sourceDifficulty,
    cells,
    selected,
    noteMode,
    completed,
    startedAt
  },
  practiceStats: {
    totalCompleted: 0,
    lastTrainingDifficulty: null,
    consecutiveCompletedByDifficulty: {
      warmup: 0,
      steady: 0,
      standard: 0,
      advanced: 0
    },
    recentLevelIdsByTrainingDifficulty: {
      warmup: [],
      steady: [],
      standard: [],
      advanced: []
    }
  }
}
```

## 功能四：完成后成长反馈升级

完成反馈可以先做方案，是否实现放到后续开发决策。

### 信息结构

完成弹窗最多展示三类信息：

- 今日：`今日完成 2 局`
- 连续：`连续除锈 3 天`
- 进度：闯关显示 `已完成 5/24`，自由练习显示 `当前训练：稳定`

### 闯关完成页

闯关完成页保持目标感：

- 标题：`闯关完成`
- 副标题：轻量鼓励语。
- 统计：`已完成 x/24`、`连续除锈 x 天`。
- 主按钮：`下一关`。

### 自由练习完成页

自由练习完成页强调训练节奏：

- 标题：`训练完成`
- 副标题：根据用时和难度生成轻量反馈。
- 统计：`今日完成 x 局`、`连续除锈 x 天`、`当前训练：稳定`。
- 主按钮：`下一局`。
- 次按钮：`换难度`。

## 数据兼容

旧存档必须继续可用。

### 兼容策略

- 如果没有 `growthStats`，初始化为空统计。
- 如果已有 `completedLevelIds`，可用它推导 `campaignCompletedCount`。
- 如果已有 `dailyReport`，不强依赖它迁移连续练习，因为历史日期可能不完整。
- 如果旧 `practiceStats` 字段存在，尽量保留 `totalCompleted` 和 `lastDifficulty`，并映射到新结构。
- 如果旧主线 `activeRun` 没有 `mode`，默认视为 `campaign`。

### 日期规则

连续练习按本地自然日计算，日期格式使用 `YYYY-MM-DD`。

需要避免：

- 用毫秒间隔简单判断一天，因为跨时区或凌晨边界容易误判。
- 把未完成局计入连续练习。
- 一天内多次完成导致连续天数重复增加。

## UI 设计原则

- 首页可以展示连续练习和闯关进度，但要保持轻，不能压过两个主入口。
- 闯关页面展示 `第 x/24 关`，给玩家清晰目标。
- 自由练习推荐语要像建议，不像系统命令。
- 完成弹窗信息最多三项，避免又变得拥挤。
- 所有新增控件继续避开微信右上角胶囊区域。
- 底部数字输入区保持贴近屏幕下沿，不能因为顶部成长信息被整体上推。

## 测试与验收

### 连续练习

- 同一天完成多局，`currentStreak` 只增加一次，`todayCompletedCount` 正确增加。
- 连续两天完成，`currentStreak` 正确增加。
- 间隔超过一天完成，`currentStreak` 重置为 `1`。
- `bestStreak` 只在当前连续天数超过历史最高时更新。

### 闯关 24 关

- 关卡数量为 `24`。
- `LAB-01` 到 `LAB-24` ID 顺序正确。
- 每关都是合法 `9x9` 数独且唯一解。
- 难度分布符合 `4/6/8/6` 的节奏。
- 首页、游戏页、完成页展示 `x/24` 进度。

### 自由练习

- 首次进入自由练习时进入难度选择页。
- 有未完成练习局时直接恢复。
- 有闯关历史但无练习历史时，推荐难度与闯关进度匹配。
- 完成两局同难度后，下一局候选难度可以上浮一级。
- 自由练习完成不改变闯关完成进度。

### 审核安全

- 新增文案不包含医疗承诺、疾病预防、概率降低等表达。
- 新增功能不包含货币、商城、会员、红包、兑换码或提现。
- 不新增用户隐私授权、位置、相册、手机号等能力。

## 推荐实施顺序

1. 增加 `growthStats` 数据结构和连续练习计算函数。
2. 将闯关包扩展到 `24` 关，并更新难度曲线测试。
3. 在首页、游戏页、完成页展示轻量闯关进度和连续练习。
4. 重构自由练习推荐逻辑和训练难度命名。
5. 根据实际界面拥挤程度，决定是否实现完整的完成反馈升级。
