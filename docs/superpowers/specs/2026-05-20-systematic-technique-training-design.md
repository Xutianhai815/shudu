# 系统化技巧训练功能设计 Spec

## 背景

当前版本已经具备三条核心能力：

- `闯关挑战`：玩家按 24 关主线推进。
- `自由练习`：玩家可按热身、稳定、标准、进阶选择训练难度。
- `连续练习与完成反馈`：玩家完成一局后获得轻量成长反馈。

下一步需要补足的是“学习能力”。数独对很多用户的主要劝退点不是题量不够，而是卡住时不知道自己应该如何观察棋盘。`技巧训练` 的目标是把常见数独技巧整理成一个低压力工具箱，让用户愿意主动学习，而不是被系统要求学习。

## 目标

- 新增 `技巧训练` 入口，作为自由练习下的轻量学习系统。
- 一次性覆盖初阶和进阶技巧，形成完整目录。
- 每个技巧先提供一个轻量训练单元，帮助用户理解关键观察方法。
- 不记录、不展示“已掌握”“完成率”“成绩”等压力型学习状态。
- 不在用户局中提示去学习技巧，避免打断闯关或自由练习体验。
- 所有训练仍保持审核友好，不引入付费、广告、排行榜、医疗化承诺或强任务系统。

## 非目标

- 不做技巧闯关、技巧考试或技巧等级系统。
- 不显示技巧掌握度、学习进度百分比、失败次数或评分。
- 不在闯关或自由练习过程中弹出“去学习技巧”的提示。
- 不把任何技巧训练设置为闯关前置条件。
- 不在训练中直接复用当前用户局并给出当前题答案。
- 不做高级技巧的完整自动识别器；首版可以使用预设盘面和预设目标。
- 不接入云端课程、视频教程、付费课程或社交分享。

## 功能定位

`技巧训练` 是一个“数独推理工具箱”，不是第三条主线模式。

它和现有模式的关系是：

- `闯关挑战` 负责目标感和主线推进。
- `自由练习` 负责随时开一局合适难度的数独。
- `技巧训练` 负责让用户理解某一种观察方法。

用户可以主动进入技巧训练，但系统不强迫学习，也不评价用户是否学会。

## 入口设计

首版入口放在 `自由练习` 页面，而不是首页。

理由：

- 首页继续保持两个核心选择：`闯关挑战` 和 `自由练习`。
- 技巧训练更接近练习体系，不应抢主流程。
- 用户进入自由练习时，已经处于“我想练一下”的心态，更适合展示学习入口。

建议入口形态：

- 在自由练习难度选择页标题下方或难度卡片上方增加轻入口：`技巧训练`。
- 入口文案可以是：`不会从哪看起？试试技巧训练。`
- 点击后进入技巧训练目录页。

## 信息架构

技巧训练首页分为两组：

1. `初阶技巧`
2. `进阶技巧`

两组都默认可进入，不做锁定。

每个技巧卡片展示：

- 技巧名称。
- 一句适用场景。
- 难度标签：`初阶` 或 `进阶`。
- 入口按钮：`练一下`。

不展示：

- 已学、未学、已掌握。
- 完成百分比。
- 星级。
- 分数。
- 排名。

## 初阶技巧目录

初阶技巧面向大多数用户，重点是“看见线索”。

| 技巧 | 训练目标 | 用户感受 |
| --- | --- | --- |
| 认识棋盘 | 理解行、列、宫和 1-9 不重复 | 知道规则从哪里看 |
| 唯一空格 | 发现某行、列、宫只剩一个空格 | 最容易建立信心 |
| 唯一候选 | 判断某个格子只剩一个可能数字 | 学会从格子出发 |
| 数字扫描 | 围绕某个数字找它还能放哪里 | 学会按数字观察 |
| 宫内排除 | 用行列限制缩小宫内位置 | 学会区域排除 |
| 行列联动 | 理解行列与宫之间互相限制 | 进入标准推理节奏 |
| 草稿整理 | 学会什么时候记录和清理候选数 | 降低中后段混乱感 |
| 重复自检 | 理解重复提醒，不依赖答案判断 | 学会自查冲突 |

## 进阶技巧目录

进阶技巧面向更有兴趣的用户，默认不强推。

| 技巧 | 训练目标 | 首版处理方式 |
| --- | --- | --- |
| 显性数对 | 识别两个格子共享同两个候选数 | 预设候选盘面 |
| 隐性数对 | 识别某两个数字只出现在两个格子 | 预设候选盘面 |
| 指向数组 | 从宫内候选位置影响整行或整列 | 预设候选盘面 |
| 区块排除 | 用一个区块限制另一个区块 | 预设候选盘面 |
| X-Wing | 识别两行两列形成的候选矩形 | 预设候选盘面 |
| Swordfish / 剑鱼 | 识别三行三列形成的候选结构 | 预设候选盘面 |
| XY-Wing | 识别三格候选链条 | 预设候选盘面 |
| 唯一矩形 | 避免多解结构的高级排除 | 预设候选盘面 |

进阶技巧首版只要求用户理解“这个形状大概长什么样”，不要求系统能在任意棋盘中动态检测。

## 轻量训练单元

每个技巧首版只做一个训练单元，结构统一：

1. `一句话说明`
2. `示例盘面`
3. `用户完成关键一步`
4. `简短正反馈`

示例：

- 说明：`唯一空格：当一行只剩一个空格时，缺的数字就只能放在那里。`
- 任务：`看第 3 行，填出缺少的数字。`
- 操作：用户点击目标格并输入数字。
- 反馈：`对，这一行缺的就是 6。`

训练单元的目标不是完成整盘数独，而是完成一次关键观察。

### 盘面要求

- 盘面可以是完整 9x9，但只突出与技巧相关的区域。
- 初阶技巧尽量减少候选数噪音。
- 进阶技巧可以使用候选数盘面，而不是要求用户从零推导所有候选。
- 每个训练单元应在 30 秒到 2 分钟内完成。
- 错误输入只提示 `再看一下相关区域`，不使用刺眼错误反馈。

### 交互要求

- 保留现有数独输入体验：选格、数字键盘、草稿模式等尽量复用。
- 训练页可以有一个 `看提示`，但提示只解释观察方向，不直接替用户完成。
- 训练页应提供 `返回`，用户可随时退出。
- 完成后只有轻反馈，不进入结算页。

## 数据模型

首版不需要记录用户是否掌握技巧，但需要有静态技巧定义。

建议新增技巧定义结构：

```js
{
  id: 'single-empty',
  group: 'basic',
  title: '唯一空格',
  summary: '一行、列或宫只剩一个空格时，缺的数字就只能放在那里。',
  difficultyLabel: '初阶',
  lesson: {
    board,
    notes,
    focusCells,
    target: { row, col, digit },
    prompt,
    successText,
    hintText
  }
}
```

只保存静态定义，不写入 `progress`。

如果未来需要做“最近打开过的技巧”，也只建议作为本地偏好记录，不显示给用户。

## 与现有系统的关系

### 与闯关挑战

- 闯关中不提示去学习技巧。
- 闯关完成反馈不展示技巧掌握情况。
- 技巧训练不改变闯关进度。

### 与自由练习

- `技巧训练` 入口放在自由练习页面。
- 自由练习推荐难度不受技巧训练影响。
- 技巧训练完成不写入自由练习完成局数。

### 与连续练习

技巧训练首版不计入连续练习天数。

原因：

- 连续练习当前表达的是“完成一局数独”。
- 技巧训练只是短学习单元，如果计入连续练习，会让用户误以为必须学技巧维持记录。

### 与完成反馈

技巧训练完成后只显示轻量反馈，例如：

- `这个观察方法记住一点点就够用了。`
- `以后遇到类似形状，可以先从这里看。`
- `这一类线索，通常藏在行列和宫的交界处。`

不进入完整大弹窗，不展示统计卡片。

## UI 方向

技巧训练目录页延续当前“一一数独”的轻实验室气质：

- 背景保持柔和。
- 卡片少文字、强分组。
- 初阶技巧更明亮，进阶技巧更沉稳。
- 不使用锁、奖杯、勋章等压力视觉。

训练页应更像“显微镜”：

- 棋盘是主角。
- 相关行、列、宫用柔和高亮提示。
- 当前任务文案不超过两行。
- 完成反馈短而明确。

## 文案原则

允许：

- `练一下`
- `看这里`
- `这个技巧常用`
- `先观察这一行`
- `再看一下相关区域`

避免：

- `你还没掌握`
- `学习失败`
- `正确率`
- `等级不足`
- `必须完成`
- `解题能力差`

审核边界继续沿用现有规则：

- 不出现疾病预防、治疗、概率降低等医学承诺。
- 不出现金币、会员、商城、红包、兑换码等商业化系统文案。

## 第一版范围

第一版一次性包含 16 个技巧：

- 初阶 8 个。
- 进阶 8 个。

每个技巧只做 1 个轻量训练单元。

第一版交付内容：

- 自由练习页增加 `技巧训练` 入口。
- 技巧训练目录页。
- 技巧训练详情页。
- 16 个技巧定义。
- 16 个预设训练单元。
- 训练单元完成反馈。
- 对应测试覆盖技巧定义、入口流转、训练完成与非计入成长数据。

## 后续扩展

后续可以逐步扩展，但不属于首版：

- 每个技巧增加 3-5 个变体训练单元。
- 训练页支持“换一个例子”。
- 完成普通数独后展示“本局可能用到的技巧”，但只在完成后出现。
- 进阶技巧增加更完整的候选数演示。
- 把技巧训练迁移为跨平台共享定义，供 HarmonyOS 原生版本复用。

## 风险与取舍

### 风险：一次性包含 16 个技巧导致内容制作量变大

取舍：每个技巧首版只做一个轻量训练单元，避免做成完整课程系统。

### 风险：进阶技巧太难，吓退普通用户

取舍：初阶和进阶分组展示，进阶不强推、不锁定、不评价。

### 风险：训练系统让用户觉得自己在上课

取舍：不做进度、分数、考试，只做“练一下”的短任务。

### 风险：不同平台重复实现技巧数据

取舍：技巧定义应尽量放在共享数据层，平台只负责展示和输入适配。

## 验收标准

- 自由练习页面能进入 `技巧训练`。
- 技巧训练目录展示 `初阶技巧` 和 `进阶技巧` 两组。
- 16 个技巧都可打开。
- 每个技巧都有一句话说明、示例盘面、目标操作和完成反馈。
- 完成技巧训练不改变闯关进度。
- 完成技巧训练不改变自由练习完成局数。
- 完成技巧训练不增加连续练习天数。
- 闯关和自由练习过程中不会弹出学习技巧提示。
- 训练文案不包含压力型评价和审核高风险表达。
