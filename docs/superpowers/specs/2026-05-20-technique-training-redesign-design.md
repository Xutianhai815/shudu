# 技巧训练体验改版设计

## 背景

当前 `技巧训练` 已经具备基础链路：自由练习页入口、技巧目录、单步训练页和 16 个技巧数据。但真机体验暴露出三个问题：

- 入口藏在自由练习页里，用户不容易主动发现。
- 技巧训练目录在有限手机屏幕里显得文字密度过高，视觉疲劳。
- 训练关卡题面过于简化，常常只剩一个明显空格，玩家可以用最基础排除法完成，很难真正理解目标技巧。

本次改版目标是让 `技巧训练` 更像一个轻量、安静、可理解的学习入口，而不是完整课程系统或压力型成长系统。

## 设计目标

- 让玩家从首页能看见 `技巧训练`，但不抢 `闯关挑战` 和 `自由练习` 两个主入口。
- 让技巧目录从“密集说明页”变成“清爽课程索引”。
- 让每个训练关卡通过真实题面和分步观察动画，帮助玩家理解“为什么这一步能填”。
- 保持低压力：不显示掌握度、完成率、正确率、失败、等级、锁定等信息。
- 保持进度隔离：技巧训练不影响闯关进度、自由练习统计、连续练习记录。

## 非目标

- 不做完整学习成长系统。
- 不记录或展示技巧掌握状态。
- 不在普通闯关或自由练习局中弹出“去学技巧”的提示。
- 不加入付费、道具、金币、会员、商城、红包、兑换码等商业化系统。
- 不引入医疗、疾病、预防、概率降低等审核风险文案。

## 方案选择

已确认采用 `A：轻入口 + 课程目录 + 分步观察动画`。

这个方案的原则是：

- 首页入口足够近，但视觉权重低。
- 目录优先可扫读，不塞大段说明。
- 训练页通过 3-4 步观察动画讲清一个技巧。
- 进阶技巧允许局部加入候选点、矩形、鱼形等结构高亮，但仍沿用统一分步框架。

## 首页入口设计

首页新增一个低调的 `技巧训练` 入口，位置放在 `继续闯关 / 闯关挑战` 与 `自由练习` 两个主按钮下方。

入口形态：

- 使用小胶囊或细文字按钮。
- 文案为 `技巧训练`。
- 可附加非常短的辅助文案，例如 `不会从哪看？`，但默认优先保持简洁。
- 色彩使用低饱和青绿色或半透明白底，不使用主按钮的强对比深色。
- 不展示进度、推荐、完成数、学习状态。

交互：

- 点击首页 `技巧训练`，直接进入技巧训练目录。
- 原自由练习页中的 `技巧训练` 入口保留，作为次入口。
- 首页两个主模式按钮仍然是页面视觉重心。

## 技巧目录设计

目录页定位为课程索引，不是说明书。

信息结构：

- 顶部标题：`技巧训练`。
- 副标题：短句说明，例如 `选一个观察方法，练一次关键步骤。`
- 分组：`初阶技巧`、`进阶技巧`。
- 技巧卡只展示技巧名和极短副标题。

卡片内容：

- 技巧名必显示，例如 `唯一候选`、`数字扫描`、`X-Wing`。
- 副标题限制为 8-12 个汉字左右，例如 `看见唯一可能`、`观察候选结构`。
- 不展示长 summary。
- 不展示 `开始练习` 这类重复按钮文案，小卡整体可点即可。

小屏策略：

- 保证所有技巧卡在常见小屏上可触达。
- 超小屏优先隐藏副标题，只保留技巧名。
- 不为了塞说明文字牺牲触控高度。

视觉风格：

- 延续当前浅灰绿、暖黄、炭黑、青绿体系。
- 初阶用更轻的白底卡片。
- 进阶可用更低明度的半透明卡片，但不要显得被锁住。
- 不使用锁、等级、徽章、进度条等压力元素。

## 训练关卡页设计

训练页采用 `分步观察动画`。每个技巧训练不再只提供一个“几乎填满，只剩一个空格”的棋盘，而是提供能体现该技巧的真实题面片段。

页面结构：

- 顶部：返回按钮、`技巧训练` 标签、技巧名。
- 中部：当前步骤说明卡片。
- 主体：数独棋盘。
- 棋盘下方：步骤进度条或简短步骤提示。
- 底部：数字键盘。
- 不显示普通工具栏 `草稿模式 / 重开 / 清除`。

训练流程：

1. `观察范围`：高亮目标相关的行、列、宫，告诉玩家先看哪里。
2. `排除线索`：逐步点亮产生限制的数字或候选位置。
3. `形成结论`：高亮目标格，并解释为什么目标数字成立。
4. `自己填一步`：开放数字输入，玩家完成目标格。

交互规则：

- 默认进入训练页后展示第 1 步。
- 玩家点击 `下一步` 推进步骤。
- 最后一步才开放目标格数字输入。
- 只允许目标格被选择和输入。
- 输入错误数字不完成训练，但不显示红色、不播放错误音、不提示“错了”。
- 输入正确目标数字后显示完成反馈。

完成反馈：

- 文案只强调“观察到了关键线索”，例如 `这一步看清楚了。`
- 不显示分数、正确率、掌握度、失败、评级。
- 可提供 `再看一遍` 和 `返回目录`，但第一版可以只保留返回行为，避免增加复杂状态。

## 教学动画规则

动画要轻，不打断用户。

可用动画：

- 行/列/宫柔和淡入高亮。
- 关键数字轻微呼吸。
- 候选点逐个出现。
- 目标格最后出现暖黄色聚焦。
- 进阶技巧可使用细线连接候选结构，例如 X-Wing 的矩形边。

避免动画：

- 大幅抖动。
- 强烈闪烁。
- 红色错误反馈。
- 长时间不可跳过演示。
- 复杂课件式旁白。

节奏建议：

- 每步动画 600-900ms。
- 玩家可点击 `下一步` 立即跳过当前动画。
- 自动播放只推进到当前步骤展示完成，不自动替玩家进入最终填数。

## 训练题面设计原则

每个技巧需要从当前“统一空格模板”升级为独立训练题面。

题面要求：

- 目标格不能显得只是唯一空格。
- 目标区域需要保留足够干扰项。
- 题面必须能通过目标技巧得到目标结论。
- 教学步骤里高亮的线索必须和真实题面一致。
- 初阶技巧可以少量空格，但不能一眼靠缺数完成。
- 进阶技巧需要候选数数据支撑，例如数对、指向数组、X-Wing、剑鱼。

数据结构建议：

- 每个技巧训练单元包含 `board`、`solution`、`target`。
- 新增 `steps` 数组。
- 每个 step 包含：
  - `title`
  - `text`
  - `highlightCells`
  - `highlightUnits`
  - `candidateHighlights`
  - `shapeHighlights`
  - `targetVisible`
  - `inputEnabled`

示例：

```js
{
  title: '先看同一列',
  text: '这一列已经排除了 1、2、4、6。',
  highlightUnits: [{ type: 'col', index: 4 }],
  highlightCells: [{ row: 1, col: 4 }, { row: 6, col: 4 }],
  candidateHighlights: [],
  shapeHighlights: [],
  targetVisible: false,
  inputEnabled: false,
}
```

## 首批实现范围

第一版改版建议一次性覆盖结构，但训练题面可以分两档质量推进。

必须完成：

- 首页新增低调 `技巧训练` 入口。
- 技巧目录视觉降噪。
- 训练页支持分步步骤框架。
- 训练页只在最后一步开放目标输入。
- 所有 16 个技巧都有步骤数据。
- 不影响任何现有进度数据。

首批题面质量：

- 初阶 8 个技巧必须尽量使用真实题面，不再是单空格模板。
- 进阶 8 个技巧可以先做到“候选结构演示 + 目标一步”，但数据结构必须支持后续更真实题面替换。

后续增强：

- 为 X-Wing、剑鱼、XY-Wing、唯一矩形补更严格的候选结构题面。
- 增加 `再看一遍`。
- 增加更细的候选点动画。

## 测试与验收

功能验收：

- 首页能进入技巧训练目录。
- 自由练习页仍能进入技巧训练目录。
- 目录页文字密度明显降低。
- 16 个技巧仍然全部可进入。
- 训练页按步骤推进，最后一步才允许输入。
- 非目标格不能被乱填。
- 技巧训练完成后不改变闯关、自由练习、连续练习数据。

视觉验收：

- 首页 `技巧训练` 入口可见但不抢主按钮。
- 目录页在 320x568、375x667、430x932 三档尺寸下不拥挤、不溢出。
- 训练页不会出现普通工具栏。
- 动画高亮使用青绿、暖黄、半透明炭黑，不使用错误红。

文案验收：

- 不出现 `已掌握`、`完成率`、`正确率`、`学习失败`、`等级不足`。
- 不出现商业化相关词，如金币、会员、商城、红包。
- 不出现医疗、疾病、预防、概率降低等审核风险文案。

技术验收：

- Node 测试全量通过。
- 视觉快照包含首页入口、技巧目录、训练步骤页。
- H5 构建仍然通过。
- 微信预览二维码可真机打开并验证入口、目录、训练步骤。
