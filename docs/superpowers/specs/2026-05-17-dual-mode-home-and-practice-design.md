# 双模式首页与自由训练设计 Spec

## 背景

当前数独小游戏只有一条主线流程：玩家从 `LAB-01` 开始，完成一关后进入下一关，目标是逐步通关。这条路径适合有目标感的玩家，但对只想随手打开练一局、或者想自主选择难度的玩家不够友好。

为了降低益智游戏的进入压力，首页需要提供两种清晰入口：

- `闯关实验`：保持现有主线通关玩法。
- `自由训练`：用户自主选择难度，随时开一局练习。

本 spec 只定义双模式的信息架构、交互规则、存档边界和验收标准，不进入实现。

## 目标

- 首页从单入口改为双入口，让玩家进入后可以选择 `闯关实验` 或 `自由训练`。
- 保留现有主线通关路径，不破坏当前从 `LAB-01` 到 `LAB-12` 的线性进度。
- 增加低压力的自由训练路径，让用户可按难度自主开始一局。
- 明确两种模式的存档边界：自由训练不解锁主线关卡，不污染主线通关进度。
- 保留“大脑除锈”和“安静陪伴”的正向反馈，但按模式调整文案和按钮。

## 非目标

- 不在本轮增加云存档、排行榜、好友对战、分享挑战或广告变现。
- 不做无限题库生成器；第一版自由训练复用现有 12 关题池。
- 不恢复首页 12 个关卡卡片列表。
- 不做复杂训练统计页、成就墙或日历打卡。
- 不改变数独基础规则，不重新引入温度线、Arrow 等变体玩法。

## 模式命名

### 采用名称

- 主线模式：`闯关实验`
- 练习模式：`自由训练`

### 命名理由

`闯关实验` 继续沿用当前产品的“实验室”语境，同时表达目标是一路推进、完成关卡包。它比“通关模式”更轻，不像传统游戏菜单那么硬。

`自由训练` 比“练习模式”更积极，减少“我是不是水平不够才要练习”的心理负担。它表达的是自主、随时、低压力，也更贴合“大脑热身”和“除锈”的产品语气。

### 暂不采用的名称

- `通关模式`：准确但偏功能名，缺少品牌感。
- `练习模式`：清楚但略像补课，情绪价值偏弱。
- `每日训练`：容易让用户误以为每天只能玩一次，也可能和后续日报系统混淆。

## 首页信息架构

首页继续保留当前 `数独实验室 / Lab Lines Sudoku`、9×9 动态主视觉和轻实验室氛围，但操作区从单按钮改成两个模式卡片。

### 首页结构

从上到下：

1. 标题区：`数独实验室` 和 `Lab Lines Sudoku`。
2. 主视觉：当前 9×9 漂浮线索盘，可保留动态和倾斜响应。
3. 模式区：两个主卡片，分别为 `闯关实验` 和 `自由训练`。
4. 底部留白：不新增今日报告、任务、广告式提示。

### 闯关实验卡片

卡片文案按状态变化：

- 无主线存档：标题 `闯关实验`，副文案 `从 LAB-01 开始，完成 12 个数独实验。`，按钮文案 `开始闯关`。
- 有未完成主线存档：标题 `继续闯关`，副文案 `继续 LAB-xx，本局进度已保存。`，按钮文案 `继续闯关`。
- 已完成部分主线但无未完成局：标题 `闯关实验`，副文案 `已完成 x/12 个实验，继续推进下一关。`，按钮文案 `继续下一关`。

### 自由训练卡片

卡片文案按状态变化：

- 无练习存档：标题 `自由训练`，副文案 `选一个难度，给大脑做一局轻量热身。`，按钮文案 `选择难度`。
- 有未完成练习存档：标题 `继续训练`，副文案 `继续上次的 {难度名} 训练。`，按钮文案 `继续训练`。

自由训练卡片可以显示四个小难度点：`入门`、`简单`、`标准`、`挑战`，只做预览，不在首页直接开始。

## 闯关实验规则

`闯关实验` 保持现在的主线玩法。

- 第一次进入从 `LAB-01` 开始。
- 完成一关后，胜利页提供 `下一关`。
- `下一关` 按 `levels` 数组顺序推进。
- `再试一次` 使用同难度的另一张数独盘，保持当前已实现的同难度换题逻辑。
- 主线完成后写入 `completedLevelIds`。
- 主线未完成局写入主线 `activeRun`。
- 首页 `继续闯关` 只恢复主线 `activeRun`。

### 主线完成页按钮

主线完成页保留目标感：

- `下一关`
- `再试一次`
- `回首页`

如果当前关是最后一关，`下一关` 可以在第一版继续按现有逻辑回到第一关，也可以后续改成 `重新开始首轮`。本 spec 不强制调整最终关循环逻辑。

## 自由训练规则

`自由训练` 是独立路径，目标是让用户随时选择难度并完成一局，不承担主线通关压力。

### 难度选择页

点击首页 `自由训练` 且没有未完成练习局时，进入难度选择页。

难度映射：

- `入门`：对应 `intro` 题池，文案 `先找确定线索，适合 3 分钟热身。`
- `简单`：对应 `easy` 题池，文案 `节奏稳定，适合日常练习。`
- `标准`：对应 `normal` 题池，文案 `需要完整推理，慢慢拆线索。`
- `挑战`：对应 `hard` 题池，文案 `长局专注，不急着快。`

难度选择页需要提供返回首页入口。第一版不提供题目列表，只提供难度选择。

### 题目选择策略

第一版自由训练复用现有 12 关题池。

- 用户选择难度后，从对应 difficulty 的关卡池里选一题。
- 优先选择该难度下与最近一次练习不同的题。
- 如果该难度只有一题，则允许重复。
- 题目仍使用现有 `createPuzzleState(level)` 创建，不额外生成新题。

### 练习局存档

自由训练未完成局写入独立的 `practiceRun`，不覆盖主线 `activeRun`。

首页如果同时存在主线未完成局和自由训练未完成局：

- `闯关实验` 卡片显示 `继续闯关`。
- `自由训练` 卡片显示 `继续训练`。
- 两者互不抢占。

### 练习完成规则

自由训练完成后：

- 不写入 `completedLevelIds`。
- 不解锁主线下一关。
- 可以更新 `dailyReport`，因为它仍然代表用户今天完成了一次训练。
- 可以更新轻量练习统计，例如 `practiceStats.totalCompleted` 和 `practiceStats.lastDifficulty`。
- 可以显示“大脑除锈完成”，但文案应更偏训练，不强调通关推进。

## 自由训练完成页

自由训练完成页按钮和主线不同：

- `再练一局`：同难度换另一张题。
- `换个难度`：回到自由训练难度选择页。
- `回首页`

完成文案建议：

- 短局：`热身训练完成`
- 中等时长：`稳定训练完成`
- 长局：`专注训练完成`

统计卡片仍可显示 `今日训练` 和 `+0.01%` 娱乐化除锈值，但必须保留既有安全边界：不做医学承诺，不出现疾病预防表达。

## 游戏页模式标识

游戏页顶部需要让玩家知道当前在哪个模式。

### 闯关实验

保持现有主线关卡信息，例如：

- `LAB-04 轻量推理`

### 自由训练

自由训练不应伪装成主线 LAB 进度。顶部建议显示：

- `自由训练 · 入门`
- `自由训练 · 简单`
- `自由训练 · 标准`
- `自由训练 · 挑战`

题目内部仍可保留原 level id 用于调试和数据，但玩家主视觉上不应误解为主线完成了某一关。

## 安静陪伴系统适配

安静陪伴系统继续按题目 difficulty 分层，而不是按模式分层。

- `intro/easy` 仍使用轻量提示和较低提示上限。
- `normal/hard` 仍保留更完整的专注时长和长局陪伴。
- 过程反馈仍只提醒投入、节奏和线索，不判断答案对错。
- 自由训练中不播放错误音效，不用颜色或声音判断正确性。

自由训练可以在完成页使用更轻的训练语气，避免让用户觉得练习也变成考试。

## 数据模型

建议扩展本地进度结构。

当前主线字段继续保留：

```js
{
  activeRun: {
    levelId,
    cells,
    selected,
    noteMode,
    mistakes,
    completed
  },
  completedLevelIds: [],
  dailyReport: {}
}
```

新增字段：

```js
{
  practiceRun: {
    mode: 'practice',
    levelId,
    difficulty,
    cells,
    selected,
    noteMode,
    mistakes,
    completed
  },
  practiceStats: {
    totalCompleted: 0,
    lastDifficulty: null,
    recentLevelIdsByDifficulty: {
      intro: null,
      easy: null,
      normal: null,
      hard: null
    }
  }
}
```

主线 `activeRun` 可以补充 `mode: 'campaign'`，但旧存档没有 `mode` 时必须按主线处理，保证兼容。

## 场景状态

运行时建议从当前的 `scene = 'menu' | 'playing'` 扩展为：

- `menu`：首页双模式入口。
- `practiceDifficulty`：自由训练难度选择页。
- `playing`：游戏页，通过 `currentMode` 区分主线或自由训练。

新增运行时字段：

```js
let currentMode = 'campaign';
```

进入主线时设置为 `campaign`。进入自由训练时设置为 `practice`。

## 错误与边界

- 如果 `practiceRun` 指向不存在的 level，忽略该练习存档并回到自由训练难度选择页。
- 如果某个 difficulty 没有可用关卡，难度卡片禁用并显示 `暂未开放`。当前 12 关题池已覆盖四档难度，正常不会触发。
- 如果旧存档没有 `practiceRun` 或 `practiceStats`，按空数据处理。
- 如果用户从自由训练返回首页，必须保存自由训练进度到 `practiceRun`，不覆盖主线。
- 如果用户在自由训练中点 `回首页`，首页自由训练卡片应能显示 `继续训练`。
- 如果用户完成自由训练，`practiceRun` 应清空或标记 completed，避免首页继续显示已完成的练习局。

## 测试要求

### 数据与存档

- 旧存档没有 `practiceRun` 时能正常启动。
- 主线 `activeRun` 和自由训练 `practiceRun` 可以同时存在。
- 完成自由训练不会写入 `completedLevelIds`。
- 完成自由训练会更新 `dailyReport`。
- 完成主线仍会写入 `completedLevelIds`。

### 首页布局

- 首页输出两个模式卡片：`闯关实验` 和 `自由训练`。
- 没有存档时，闯关卡片显示 `开始闯关`，自由训练卡片显示 `选择难度`。
- 有主线未完成局时，闯关卡片显示 `继续闯关`。
- 有自由训练未完成局时，自由训练卡片显示 `继续训练`。
- 首页仍不显示 12 个关卡卡片。

### 难度选择

- 点击自由训练卡片进入难度选择页。
- 难度选择页包含 `入门`、`简单`、`标准`、`挑战`。
- 点击 `入门` 启动 difficulty 为 `intro` 的题。
- 点击 `挑战` 启动 difficulty 为 `hard` 的题。
- 难度选择页返回按钮能回首页。

### 游戏运行时

- 主线游戏页顶部显示 LAB 信息。
- 自由训练游戏页顶部显示 `自由训练 · {难度名}`。
- 自由训练完成页显示 `再练一局`、`换个难度`、`回首页`。
- 主线完成页仍显示 `下一关`、`再试一次`、`回首页`。
- 自由训练 `再练一局` 保持同难度换题。
- 自由训练 `换个难度` 返回难度选择页。

### 反馈安全

- 两种模式过程输入都不通过颜色或声音判断对错。
- 两种模式都不播放 `error` 音效。
- 完成反馈不出现 `老年痴呆`、`阿尔茨海默`、`医学`、`疾病` 等医疗宣称词。

## 验收标准

- 用户进入首页后能清楚看到两个选择：`闯关实验` 和 `自由训练`。
- 不想通关的用户可以在 2 次点击内进入自由训练难度选择并开始一局。
- 自由训练不影响主线关卡解锁和主线完成状态。
- 主线未完成局和自由训练未完成局可以并存，并分别继续。
- 完成自由训练后，用户得到正向反馈，但不会被误导为完成了主线关卡。
- 首页保持轻、干净、有品牌感，不变成复杂模式大厅。

## 实施建议

建议拆成 5 个实施阶段：

1. 数据层：扩展 progress，加入 `practiceRun` 和 `practiceStats`，保证旧存档兼容。
2. 首页层：把单按钮首页改成双模式卡片，并增加 hit test。
3. 难度选择层：新增自由训练难度选择布局、渲染和命中。
4. 运行时层：加入 `currentMode`，区分主线开始、自由训练开始、继续训练、完成页按钮。
5. 验证层：补全 Node 测试、视觉快照和微信开发者工具预览码。

## Spec 自检

- 无未定占位符。
- 已明确模式命名、首页入口、难度映射和完成页按钮。
- 已明确自由训练不写入 `completedLevelIds`，避免污染主线。
- 已明确旧存档兼容策略。
- 已明确本轮不做云能力、排行榜、无限题库、成就系统或新规则变体。
